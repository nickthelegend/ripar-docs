# Quickstart

By the end of this page you will have a public HTTPS endpoint that charges USDC per
request and is discoverable by any agent on the network.

<Callout type="note" title="What you need">
  Node 20+, an Algorand address to receive funds (Pera, Defly or any wallet), and a
  Ripar account from [app.ripar.io](https://app.ripar.io).
</Callout>

## 1 · Install the CLI

```bash
npm install -g @ripar/cli
ripar login
```

`ripar login` opens a browser, and writes a token to `~/.ripar/config.json`. Everything
below uses that token.

## 2 · Create a project

```bash
ripar init summarize --template node
cd summarize
```

The template is an ordinary HTTP handler. There is nothing blockchain-shaped about it —
that is the point:

<LangTabs labels={["TypeScript", "Python"]}>

```ts title="src/index.ts"
import { defineEndpoint } from "@ripar/sdk";

export default defineEndpoint({
  name: "summarize",
  // What a caller pays, per request, in USDC.
  price: "$0.01",
  handler: ({ body }) => {
    const { text } = body as { text: string };
    return { summary: text.slice(0, 280) };
  },
});
```

```python title="main.py"
from ripar import define_endpoint

# What a caller pays, per request, in USDC.
@define_endpoint(name="summarize", price="$0.01")
def summarize(body):
    return {"summary": body["text"][:280]}
```

</LangTabs>

Every option on `defineEndpoint` — timeouts, input schemas, private endpoints — is in
the [SDK reference](/reference/sdk).

## 3 · Set where you get paid

```bash
ripar config set payout ADDR…YOUR_ALGORAND_ADDRESS
```

<Callout type="warning" title="Ripar never holds your balance">
  Payments settle directly from the caller to the address you set here. Ripar routes,
  prices, verifies and records — it is never a custodian. See [Custody
  model](/concepts/custody).
</Callout>

## 4 · Deploy

```bash
ripar deploy
```

✓ payout address   ADDR…K7QX
✓ price            0.01 USDC / request

## 5 · Call it and watch it charge

An unpaid request is refused with the price attached:

```bash
curl -i https://api.ripar.io/a/summarize \
  -H 'content-type: application/json' \
  -d '{"text":"..."}'
```

```http
HTTP/1.1 402 Payment Required
X-Payment-Required: {"amount":"0.01","asset":"USDC","network":"algorand","payTo":"ADDR…K7QX"}
```

Retry it with a client that handles the payment leg for you. The handshake is
identical in every language — only the wrapper differs:

<LangTabs>

```ts title="pay.ts"
import { RiparClient } from "@ripar/sdk";

const ripar = new RiparClient({
  mnemonic: process.env.RIPAR_WALLET_MNEMONIC,
  maxPrice: "0.02", // refuse anything above this, whatever the quote says
});

const res = await ripar.call("https://api.ripar.io/a/summarize", {
  text: "a long article…",
});

console.log(res.data);         // { summary: "…" }
console.log(res.payment?.txId); // 7A2F…9C1B
```

```python title="pay.py"
import os
from ripar import RiparClient

ripar = RiparClient(
    mnemonic=os.environ["RIPAR_WALLET_MNEMONIC"],
    max_price="0.02",  # refuse anything above this, whatever the quote says
)

res = ripar.call("https://api.ripar.io/a/summarize", {"text": "a long article…"})

print(res.data)          # {"summary": "…"}
print(res.payment.tx_id) # 7A2F…9C1B
```

```bash title="pay.sh"
# curl can carry a payment header but cannot produce one — signing needs a key.
# Take the header from a client, or let `ripar call` do both legs at once:
#   ripar call summarize --data '{"text":"a long article…"}'
curl -s https://api.ripar.io/a/summarize \
  -H 'content-type: application/json' \
  -H "X-PAYMENT: $RIPAR_PAYMENT" \
  -d '{"text":"a long article…"}'
```

</LangTabs>

```ansi title="output"
→ 402  price 0.01 USDC
→ paid 0.01 USDC  tx 7A2F…9C1B  (2.8s)
← 200  {"summary":"…"}
```

That transaction is on Algorand MainNet. The USDC is in your wallet, not in an account
on Ripar waiting for a payout run.

## What just happened

1. Your handler was packaged and given a public HTTPS route.
2. Ripar wrapped it in x402 middleware that refuses unpaid calls with a price.
3. The endpoint was registered with the Bazaar so agents can discover its schema.
4. A caller paid, the facilitator verified, and your handler ran exactly once.
